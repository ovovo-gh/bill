# 余有 · 个人资产簿

为 ovovo-gh/bill 制作的个人余额管理网页。静态页面部署到 GitHub Pages，Cloudflare Worker + D1 提供加密同步。无第三方前端依赖，无需日常注册登录。

## 功能

- 自定义账户名称、分类、颜色、备注，直接修改当前余额。
- 人民币、港币、日元、欧元；外币保留原币余额，并按每日参考汇率折合人民币。
- 显示总资产、总负债、净资产，信用卡欠款按正数输入并自动扣除。
- 搜索、分类筛选、修改历史、归档和恢复。归档账户不参与合计。
- 两台设备使用同一同步密钥，打开页面和每 30 秒检查同步。
- AES-GCM 加密本地缓存、云端数据和导出备份；云端不接收明文账目和主密钥。
- 修改冲突停止上传，保留本机修改；重新连接时先导出本机备份，再读取云端。
- 响应式手机 / 电脑界面，一键隐藏金额。

## 本地预览

需要 Node.js 20+ 与 Python 3。

```sh
npm test
npm run dev
```

打开 http://127.0.0.1:4173 。`npm run build` 将静态页面复制到 dist/。

首次进入时账本为空。尚未接入云端时页面显示“仅此设备 · 未连接同步”，不能跨设备同步。这个阶段浏览器会生成并记住本地密钥；在“同步设置”里复制并保存。

## 免费同步服务部署

使用 Cloudflare Workers Free 与 D1 Free。不要开启付费套餐。免费额度和限制以 Cloudflare 官方页面为准，超额时同步可能不可用；客户端会保留待上传修改。

1. 注册 Cloudflare 免费账号并验证邮箱。
2. 通过官方 Wrangler CLI 登录（仅部署时使用）：

```sh
cd backend
npx wrangler@4 login
npx wrangler@4 d1 create yuyou-bill
```

3. 将返回的数据库 ID 写入 `backend/wrangler.jsonc` 的 `database_id`。这是资源 ID，不是密钥。
4. 初始化数据库并部署：

```sh
npx wrangler@4 d1 execute yuyou-bill --remote --file=schema.sql
npx wrangler@4 deploy
```

5. 把部署输出的 HTTPS Worker 地址写入 `public/config.js` 的 `SYNC_URL`，然后提交发布。或在网页“同步设置”输入该地址。
6. 在第一台设备复制保存同步密钥，点击“连接并同步”。在第二台设备填入相同密钥和服务地址。

同步服务仅允许 `https://ovovo-gh.github.io` 和本机预览来源跨域访问。改域名时需更新 `ALLOWED_ORIGINS`。`/health` 仅检查服务存活，数据库和跨设备同步需在部署后实际联调。

## GitHub Pages 发布

仓库： https://github.com/ovovo-gh/bill

在仓库 Settings → Pages → Build and deployment → Source 选择 GitHub Actions。推送 main 后，`.github/workflows/pages.yml` 会运行测试、构建并发布。

预期网址： https://ovovo-gh.github.io/bill/ （只有发布成功后才可访问）。

只发布 `dist/` 的静态资源；后台源码、测试、备份和实际账目不会包含在 Pages 产物中。请勿将用户密钥、浏览器数据、云端凭据或导出备份加入仓库。

## 数据与同步说明

- 同步密钥是浏览器生成的 256 位随机值；持有它可访问账本，请自行备份。浏览器会记住它，因此能访问此浏览器的人也能访问账本。
- 本地 AES-GCM 加密主要避免缓存出现明文；密钥同在此浏览器，不能防御本机被控制或同源恶意脚本。页面不引入第三方脚本。
- 主密钥通过带用途前缀的 SHA-256 派生为独立的账本 ID、认证凭据和 AES 密钥。服务端仅存认证凭据的哈希和密文。
- 每次保存生成新的随机 IV；数据库使用版本条件更新，拒绝旧版本覆盖。
- 离线修改在已经打开的页面内可保存，联网后重试。尚未实现离线首次加载或安装式 PWA。
- 同步冲突不自动合并。保留本机加密备份后，可读取云端版本并重新应用所需修改。
- 已打开另一标签页时，检测到该标签页修改会要求刷新，防止覆盖。
- 金额按最小货币单位存储，人民币/港币/欧元到分，日元到整数；输入为非负数，负债由账户类型决定。币种在创建后固定，以免历史记录单位混乱；需改变币种时新建账户并归档旧账户。
- 汇率来源： https://frankfurter.dev/ ，按每日中间参考价估算，不代表现金兑换成交价。断网时保留缓存并显示日期；没有可用汇率时不显示可能漏算的合计。
- 加密备份必须使用导出时的密钥恢复；丢失所有密钥副本后无法找回账目。

## 验证

`npm test` 覆盖金额精度、多币种合计、负债/归档、数据校验、加密、鉴权、跨域、请求大小和并发版本冲突。Worker 测试使用内存 D1 适配器；不替代正式 Cloudflare 部署后的联调。
